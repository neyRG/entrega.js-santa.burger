# La Santa Burger

Sitio web para presentar el menú de La Santa Burger, con un carrusel de combos y una galería de hamburguesas.

## Tecnologías

- HTML
- Sass (SCSS)
- CSS

## Uso local

Abre `index.html` en el navegador para ver el sitio.

Para compilar los estilos después de modificar los archivos Sass:

```bash
sass sass/main.scss style/style.css
```

Para recompilar automáticamente mientras trabajas:

```bash
sass --watch sass/main.scss style/style.css
```
